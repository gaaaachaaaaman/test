# 広告タスク管理ツール

広告事業のタスクを一元管理する、スマホ最適化PWAアプリケーション。

## 🌟 特徴

### スマホファースト設計
- **スワイプ操作**: タスクを左右にスワイプしてステータスを瞬時に変更
- **PWA対応**: ホーム画面に追加してアプリのように使える
- **オフライン動作**: ローカルストレージでデータ保存、ネット不要
- **音声入力**: タスク名を音声で入力可能（対応ブラウザのみ）

### 広告事業特化機能
- **クライアント管理**: プロジェクトごとにクライアントを設定
- **キャンペーン管理**: キャンペーン単位でタスクをグループ化
- **タスクタイプ**: 制作、企画、入稿、分析、打合せなど業務に応じた分類
- **予算トラッキング**: タスクごとに予算を設定・管理

### 直感的なUI/UX
- **カラーコーディング**: 優先度とクライアントを色で視覚化
- **ワンタップフィルタ**: ステータス、優先度、クライアント別に瞬時にフィルター
- **期限アラート**: 期限が近いタスクを自動で強調表示
- **統計ダッシュボード**: タスクの進捗状況を一目で把握

## 🚀 使い方

### セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

http://localhost:3000 にアクセス

### ビルド

```bash
# 本番環境用ビルド
npm run build

# 本番環境サーバーの起動
npm start
```

### PWAとしてインストール

1. スマホのブラウザでアプリにアクセス
2. 「ホーム画面に追加」を選択
3. アプリとして起動可能に！

## 📱 操作方法

### タスクの作成
- 右下の「+」ボタンをタップ
- フォームに情報を入力
- 音声入力ボタン（🎤）で音声入力も可能

### タスクのステータス変更
- **左スワイプ**: 次のステータスへ（未着手 → 進行中 → レビュー → 完了）
- **右スワイプ**: 前のステータスへ

### フィルタリング
- 検索バーでキーワード検索
- ステータス、優先度、タイプ、クライアントでフィルター
- 複数条件の組み合わせ可能

## 🛠 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **PWA**: next-pwa
- **データ保存**: LocalStorage
- **状態管理**: React Context API

## 📂 プロジェクト構造

```
/
├── app/                  # Next.js App Router
│   ├── layout.tsx       # レイアウト
│   ├── page.tsx         # メインページ
│   └── globals.css      # グローバルスタイル
├── components/          # Reactコンポーネント
│   ├── SwipeableTaskCard.tsx  # スワイプ可能なタスクカード
│   ├── FilterBar.tsx          # フィルターバー
│   └── TaskForm.tsx           # タスク作成フォーム
├── contexts/            # Reactコンテキスト
│   └── AppContext.tsx   # アプリケーション状態管理
├── lib/                 # ユーティリティ
│   ├── storage.ts       # ローカルストレージ管理
│   └── utils.ts         # ヘルパー関数
├── types/               # TypeScript型定義
│   └── index.ts
└── public/              # 静的ファイル
    └── manifest.json    # PWAマニフェスト
```
